# Changelog

## 1.1.0 — First public source release

- Offline Flutter course-risk app with first-run profile and persistent day/night appearance.
- Dated grade entry, reversed grading scales, missing-data handling, and course prioritization.
- One shared PyTorch model with a numerical Dart export and cross-runtime parity fixtures.
- Python inference CLI, local HTTP API, training pipeline, and frozen evaluation outputs.
- Public setup guides, architecture and model documentation, source attribution, and CI.

The supplied APK was built before this repository was published. This release packages the source and existing Android build; it does not claim a newly trained model or physical-device validation.
